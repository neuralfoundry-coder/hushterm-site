지원

Hushterm 사용 중 문제나 제안이 있으면 GitHub 이슈로 알려 주세요. 서버 주소, 키, 비밀번호는 적지 마세요.

자주 묻는 질문

접속이 안 돼요

호스트 목록에서 서버를 길게 눌러 연결 진단을 실행하세요. DNS, 포트, 호스트 키, 인증 단계 중 어디서 실패하는지 알려 줍니다.

호스트 키가 바뀌었다고 나와요

서버를 다시 설치했거나 다른 서버로 바뀐 것이 아니라면 접속하지 마세요. 확실하다면 진단 화면에서 저장된 호스트 키를 지울 수 있습니다.

AI가 동작하지 않아요

기기 내 AI는 Apple Intelligence를 지원하는 기기에서 설정을 켠 경우에만 동작합니다. 그렇지 않아도 위험 명령 경고와 규칙 기반 도움말은 계속 동작합니다.

구독과 평생 이용권

Pro는 설정 > Hushterm Pro에서 구입하고 복원할 수 있습니다. 구독은 설정 > Apple ID > 구독에서 관리하거나 취소합니다.
